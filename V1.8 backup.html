How values work

Purchase cost is stored in USD using the exchange rate you enter for the purchase date. Current value is your manually entered market estimate in USD. Gain/loss = (current value − purchase cost − grading costs) ÷ (purchase cost + grading costs) × 100. Sold-card profit subtracts actual selling fees and shipping. No automatic current-price feeds are connected yet. Historical exchange-rate lookup requires internet; screenshot prices are manually transcribed.

Add cards directly to Collection, Grading, Selling, Trading, SEALED PRODUCTS, or Inspection. Choose an existing vault or type a new name. Each graded slab can be entered directly into Collection without a condition-review step. Each graded slab can have its own record; ETBs, tins, sealed packs, booster boxes, booster cases, bundles, and collection boxes can be grouped by quantity. SEALED PRODUCTS is a separate top-level section with customizable vaults. Photos and screenshots are compressed and saved with the card in this browser. Large collections may exceed browser storage. The app saves data in this browser on this device only. Use Backup JSON regularly; clearing Safari website data or changing devices can erase local records.
